Feature Name: SKU Creation and Assignment

Short Description

SKU Creation and Assignment is a feature that gives each inventory item a unique Stock Keeping Unit (SKU) code. The SKU helps the store identify and manage items easily.

Purpose

The purpose of this feature is to make it easy to identify each item in the store and prevent confusion between similar products.

Main Functions/Activities

- Create a unique SKU for each item.
- Assign an SKU to a product.
- Record the item name and its SKU.
- Search for an item using its SKU.
- View the details of an item using its SKU.
- Prevent duplicate SKU codes.
