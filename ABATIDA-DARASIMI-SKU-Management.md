# Feature Name: Intelligent SKU Generation and Classification

## Student: ABATIDA DARASIMI
## Group: Item Identification (SKU Management) - Group 1

### Short Description
This feature automatically generates a unique Stock Keeping Unit (SKU) code for every new item and classifies it based on category, brand, and attributes. It generates barcode linked to SKU.

### Purpose
To ensure every item has a unique identity, avoid duplication, make searching faster, and allow scanning instead of manual typing.

### Main Functions
- Auto-generate unique SKU using format: CATEGORY-BRAND-SEQUENCE e.g., ELEC-SAMSUNG-0001
- Validate SKU to prevent duplicate entries
- Allow manual editing with admin approval
- Assign category and sub-category to each SKU
- Generate barcode/QR code for each SKU
- Search and filter items using SKU or barcode
- Maintain SKU history log for audit
