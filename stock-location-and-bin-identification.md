# Stock Location and Bin Identification

## Short Description

Stock Location and Bin Identification is a feature used to record where products are stored in a store or warehouse. Each storage area, shelf, rack, or bin can have an identification code.

## Purpose

The purpose is to help store workers quickly know where products are located and make it easier to find and organize stock.

## Main Functions/Activities

* Assign a storage location to each product.
* Give shelves, racks, or bins identification codes.
* Record the location of each product.
* Help workers quickly find products.
* Track products when they are moved to another location.
* Update the storage location when necessary.
* Support stocktaking and physical inventory checks.
