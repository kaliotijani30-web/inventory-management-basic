# Feature Name: Bin Location and Reorder Management

### Purpose
To reduce time searching for items and prevent stock-outs.
### Main Functions
- Assign bin location code e.g., A-01-02-03
- View items by location
- Alert when stock goes below reorder level

- Track item movement between bins
- Report for overstocked items
